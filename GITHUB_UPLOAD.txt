REDMI BATTERY DIAGNOSTIC - GITHUB BUILD

1) Create a new empty repository on github.com.
2) Extract RedmiBatteryDiag-GitHubReady.zip.
3) In the repository, choose Add file > Upload files.
4) Upload all extracted project files and folders to the repository root.
   IMPORTANT: .github/workflows/build-apk.yml must be present in the repository.
5) Commit to the main branch.
6) Open Actions > Build Android APK.
7) The build should start automatically. If not, click Run workflow.
8) When the build is green, open the run.
9) Under Artifacts, download RedmiBatteryDiag-APK.
10) Extract the downloaded ZIP and install RedmiBatteryDiag.apk on the phone.

No Android Studio, Java, Gradle or Android SDK installation is needed on your PC.
